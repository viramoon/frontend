# 前端组件测试

从仓库根目录运行 `pnpm test`。Vitest 在 jsdom 中启动 React，Testing Library 通过页面角色、文本和导航链接读取用户可见的结果。使用查询的用例各自创建 TanStack Query 客户端，并在结束时清理视图和缓存。

仪表盘测试使用正式路由和生成的 web 客户端，仅替换同源 HTTP 响应。覆盖等待、下游出错、单个请求失败时保留另一部分数据、示例 404、完整结果以及四个页面间的导航。成功用例逐字检查长十进制金额，并核对客户端实际请求的地址。[组件用例](dashboard.test.tsx)

浏览器访问实际 web 服务的代理配置和构建步骤见 [构建说明](../../docs/build.md)。

行情终端测试在 jsdom 下检查 fixture、状态标记和来源。图表用例验证精确读数、交互及 Canvas 不可用时的降级。[终端测试](market.test.tsx) · [图表测试](chart.test.tsx)

Git 防护测试在临时仓库生成合规和违规样本。浏览器渲染用例单独使用本地构建，检查宽屏与窄屏渲染。执行方式见[防护本地复测](../../docs/data-guard.md#本地复测)。

路由用例覆盖新旧深链、策略详情及系统和示例回测的 404 处理。键盘用例用 Testing Library 的 user-event 模拟 `Tab` 和 `Enter`，验证焦点顺序和导航结果。焦点样式用例将实际样式表的 `:focus-visible` 映射为 jsdom 支持的 `:focus`，再检查计算出的轮廓。在浏览器中验收实际 Canvas、焦点轮廓和窄屏抽屉焦点。[路由测试](routes.test.tsx) · [终端验收](../../RUNBOOK.md#验证行情终端)

U2a 覆盖十二个自选标的、SPY 的 L1 限制、marketDataType 与独立新鲜度、市场时区与周期持久化、合成指标列、Binance 部署开关和区域限制、深度额度、盘口失同步、恢复与迟到事件。订单簿单元测试使用超过 JS 安全整数的序号和价格。[U2a 行情用例](market-u2a.test.tsx) · [订单簿状态用例](order-book.test.ts)

十二标的切换用例分别在 1 小时和 4 小时周期运行。每次选择都核对 L1 最优买卖价及数量、最近报价和末根闭合 K 线的 OHLCV 原文。AAPL 先从未闭合预览切回末根闭合 K 线。[逐标的读数测试](market-u2a.test.tsx)

U2b 在显式回放模式中通过路由核对观察、核验、假设、实测项和 OI 日期，测试精确权利金额筛选、证据与缺口、情景与 0DTE、wall、flip、覆盖及读取状态。用例拒绝期权页发起 HTTP、WebSocket 或 SSE，并验证没有下单入口。离线浏览器核对两路由首屏和窄屏键盘操作。[组件用例](options-u2b.test.tsx) · [离线渲染](../../scripts/visual-market.test.mjs)

成交条件和置信度各有独立的结果集断言。SPY 和 AAPL 的 flip 用例检查同号网格和异号夹点，并用两端的净 GEX 验证返回的过零点。

研究工作台用例在正式路由中验证两条 YAML 入口、行列诊断、精确十进制结果、只读研究、因子衰减和按键恢复。额外覆盖 YAML 非字符串键、数值精度与字段路径、等价格式下的错误定位，以及使用生产查询配置从离线空缓存加载目录、报告与作业。通过假响应模拟提交结果丢失和重试，逐例断言 fixture 页面没有发起 HTTP 请求。[研究工作台测试](research.test.tsx)

U4 正式路由用模拟同源 HTTP 验证 W3/W4 的生成客户端、管理员会话、测试邮件、集成配置与版本操作，以及精确水位和缺口。Drive 用例固定文件观测时间并推进服务端年龄，验证告警与事件状态，并核对降级及缺少恢复点时的历史事件和持续告警筛选。系统路由用例通过默认路由覆盖系统 404、503 及示例回测 404 空态。候选版本、凭据与恢复状态也使用显式注入的合成适配器测试。[W3 用例](operations-web.test.tsx) · [W4 用例](integrations-web.test.tsx) · [合成用例](operations.test.tsx)

W2a 用例走默认行情路由和生成客户端。固定 UTC WAL 记录验证盘口与逐笔起点、截止日期、精确价格和序号、WebSocket、SSE 权限撤回、自选 revision 及 focus 写入。所有传输都由测试替换。[W2a 线路测试](market-web.test.tsx)

U9 在告警与通知规则用例中使用固定合成 UUID、时间和维护原因。显式切换 W5 的 `active` 标志模拟到期，检查列表和详情、键盘提交与解除、UTC 截止时间、同源写入头、超时后的核对及权限拒绝。离线浏览器检查 320 像素视口中的日期、原因和提交控件及键盘顺序。[W5 接线用例](operations-web.test.tsx) · [离线浏览器测试](../../scripts/visual-market.test.mjs)

第 2 批契约用例使用固定 UTC 时间、虚构合约号、手写因子和作业常量，以及已有合成 YAML。无随机种子。测试只替换同源 Fetch 响应。W2b 覆盖校验行列、上传与选版后的提交、登记哈希冲突、幂等找回、精确报表、匿名权限和超过 JavaScript 安全整数的 ID 与游标。旧示例、目录版本与作业深链测试从默认路由直接进入，作业用例按原会话格式准备合成记录。另校验正式目录链接在策略 ID 或版本相同时进入 W2b。W8/W9 覆盖期权链续页、场所精确档位及重置、0DTE、OI、后端 wall/flip、报价与日期区间的证据、上游错误及匿名拒绝。敞口、观察与核验的 `404 market_read_not_found` 用例核对独立空态，其他 404 仍显示错误。[研究接线](research-web.test.tsx) · [期权接线](options-web.test.tsx)
