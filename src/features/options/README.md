# 期权流水与敞口

`/options/flow` 与 `/options/exposure` 默认通过管理员会话读取 [W8/W9 接口](../../api/README.md#期权视图适配层)。期权链以标的 IBKR ConId 读取并按 `next_after_con_id` 翻页。流水以所选合约 ConId 和 UTC 半开区间查询观察与核验；链上的合约可填入流水表单。敞口使用 Instrument ID 和服务端情景，显示全部、0DTE 和后续到期的桶、覆盖、wall 和 flip。Nasdaq 场所深度按支持的股票代码查询。服务返回的十进制字段按原文本展示，缺失采集起点显示「未知」。

显式添加 `?market=replay` 后，两页使用同一只读合成适配器。回放使用 U2a 的来源、回放、空态和时间组件。页首汇总观察、核验、已核验中的未知方向、无法回补区间数、持仓假设和 OI 基准日。以下两节描述回放界面。

## 流水

观察与核验记录、未订阅时间段使用「订单簿细节（自 YYYY-MM-DD 起）」。日期来自适配层的 UTC 采集起点。SPY、AAPL 的合成采集日起于 2026-11-19，QQQ 回放为空。

观察路径显示累计放量、报价异动、基线证据、覆盖和可能的估计权利金额。历史路径显示成交时刻、取得时间、当时的报价证据、主动方向推断与置信度、场所、原始条件码、映射版本及更正与取消。明确多腿条件和启发式的疑似 sweep、block、机构规模分别展示。同秒同价同量的两笔合成成交各有独立 ID，可分别打开证据。取消记录保留审计证据，从有效核验数和权利金额筛选中移除。

支持标的、记录类型、到期日、0DTE、最低权利金额、条件与置信度组合过滤。估计权利金额参与最低金额比较。未订阅区间独立列出半开时间窗、回补能力和原因，分钟 bar 不改变逐笔无法回补的状态。

## 敞口

摘要、GEX 分布、覆盖与输入时间、Gamma flip 和合约级输入使用「价量历史」。各面板分别保留估值时间、OI 基准日及模型覆盖。

按行权价、到期日展示绝对 gamma 集中度与三种方向假设。每项提供估值时点、模型版本和精确十进制读数，单位为标的变动 1% 对应的美元 delta 变化。柱长仅用于显示相对大小。0DTE 以估值交易业务日为准，按行权价单列该分量并在到期分布标记当日组。最大绝对集中 wall 取无方向集中度的峰值。最大正值与最大负值 wall 各取当前方向假设下的极值。合成样本并列时取较低行权价。

覆盖显示有效合约数、候选数、有效 OI、全部 OI、缺失原因、最早与最晚观察时刻。OI 分母缺失时显示「未知」。OI 基准日未证实时仍显示观察时间。合约表保留乘数和 OI、IV、gamma 的精确读数，区分零与缺失。Flip 显示「后端情景网格的过零点（当前为合成样例）」和有过零点、无过零点、未评估三种状态。已评估情景可展开查看现货价格和对应净 GEX 的网格点，并显示范围、步长、模型、IV 口径、利率和股息率。

## 合成输入与接入

生成器以 SPY 的 1801 和 AAPL 的 1802 为初始种子，32 位线性同余序列扰动虚构基价、合约 IV 和 gamma、成交价格、数量及量差。时间固定在 2026-11-19 的模拟交易日。OI、报价条件、更正及缺口由代码设定。权利金按价格、数量及对应合约乘数计算，GEX 合成桶按 D3 公式用 BigInt 定点生成。QQQ 演示空态。页面 `data-fixture-seed` 记录场景及种子，数据由本地适配器提供。[生成器](optionsFixture.ts) · [样本防护](../../../docs/data-guard.md)

合成 flip 模拟后端网格响应。以网格起点为第 0 步，Call 分量从 5750 起每步加 600，Put 分量从 11000 起每步减 400。根据情景加上方向并求和。净 GEX 为零时采用该网格价格，相邻点变号时用 BigInt 按两点线性插值。当前样例的过零点精确到分。SPY 的 Call 正 / Put 负情景在 314 和 315 的净 GEX 分别为 −250 和 750，过零点为 314.25。网格模型、IV 口径、利率与股息率是模拟响应的元数据。实际 GEX、网格和 flip 由 finance F9d 计算，经 F10c/W8 提供。前端显示服务端返回的过零价格区间和网格口径。历史成交证据由 F9e 生产，经 F10d/W9 提供。

服务返回 `finance_contract_pending` 时显示「待接入」。服务返回 `404 market_read_not_found` 时显示独立的暂无数据状态。成功空结果、未知分母、权限拒绝、上游错误及未评估 flip 分别显示。静态产物交给 web 托管，部署由 fertile 维护。[验收步骤](../../../RUNBOOK.md#验证期权页)
