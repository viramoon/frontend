# 期权流水与敞口

`/options/flow` 与 `/options/exposure` 从同一只读期权适配器读取所选标的。两页共用 U2a 的来源、回放、空态和时间组件。页首同时显示观察、历史核验、已核验中的方向未知、无法回补区间数、持仓假设与 OI 基准日。实测项展示源输入位置，本期的值均为合成回放。

## 流水

观察路径显示累计放量、报价异动、基线证据、覆盖和可能的估计权利金额。历史路径显示成交时刻、取得时间、当时的报价证据、主动方向推断与置信度、场所、原始条件码、映射版本及更正与取消。明确多腿条件和启发式的疑似 sweep、block、机构规模分别展示。同秒同价同量的两笔合成成交各有独立 ID，可分别打开证据。取消记录保留审计证据，从有效核验数和权利金额筛选中移除。

支持标的、记录类型、到期日、0DTE、最低权利金额、条件与置信度组合过滤。估计权利金额参与最低金额比较。未订阅区间独立列出半开时间窗、回补能力和原因，分钟 bar 不改变逐笔无法回补的状态。

## 敞口

按行权价、到期日展示绝对 gamma 集中度与三种方向假设。每项提供估值时点、模型版本和精确十进制读数，单位为标的变动 1% 对应的美元 delta 变化。柱长仅用于显示相对大小。0DTE 以估值交易业务日为准，按行权价单列该分量并在到期分布标记当日组。最大绝对集中 wall 取无方向集中度的峰值。最大正值与最大负值 wall 各取当前方向假设下的极值。合成样本并列时取较低行权价。

覆盖显示有效合约数、候选数、有效 OI、全部 OI、缺失原因、最早与最晚观察时刻。OI 分母缺失时显示「未知」。OI 基准日未证实时仍显示观察时间。合约表保留乘数和 OI、IV、gamma 的精确读数，区分零与缺失。Flip 区分网格有过零点、无过零点和未评估，并展示合成重估的网格范围、步长、模型、IV、利率和股息率。

## 合成输入与接入

生成器以 SPY 的 1801 和 AAPL 的 1802 为初始种子，32 位线性同余序列扰动虚构基价、合约 IV 和 gamma、成交价格、数量及量差。时间固定在 2026-11-19 的模拟交易日。OI、报价条件、更正、缺口及 flip 网格输出为可审查的预设。权利金按价格、数量及对应合约乘数计算，GEX 合成桶按 D3 公式用 BigInt 定点生成。预设 flip 输出演示前端状态。真实网格重估和交易证据由 finance F9d/F9e 生产。QQQ 演示空态。页面 `data-fixture-seed` 记录场景及种子，不向外部服务请求数据。[生成器](optionsFixture.ts) · [样本防护](../../../docs/data-guard.md)
