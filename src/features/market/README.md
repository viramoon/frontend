# 行情终端

`/dashboard` 展示主 K 线、成交量和指标，`/trading` 展示只读 L1、场所订单簿和独立逐笔成交区。两个入口在 app 层使用同一行情组件。桌面常显侧栏，960 像素以内通过按钮打开自选及报价深度抽屉。自选、选中标的、1 小时或 4 小时、UTC 或市场时区、加密产品选择和 Nasdaq 固定项存于浏览器。行情读数不写入浏览器持久存储。[MarketTerminal](MarketTerminal.tsx)

## 标的与状态

- 默认自选 QQQ、SPY、AAPL、MSFT、NVDA、AMZN、GOOGL、META、TSLA、BTC、ETH、SOL。NDX 和 VIX 保留为无权与空态演示，未加入默认已保存列表。
- SPY 仅展示美国综合 L1。其余八只股票可选择 Nasdaq 场所订单簿，界面独立显示买卖档数、同步状态和盘口时间。模拟 L1 预算为 9 行股票常驻、16 行热点期权、45 行轮换期权、30 行余量。Nasdaq 默认固定 AAPL 与 MSFT，第三个名额跟随当前页中的合资格未固定标的。
- 三种币默认展示 Hyperliquid 永续，Binance 现货和 USDT 永续使用独立的场所与标的身份。Binance 默认为部署配置关闭。页面的合成回放开关仅在当前页面使用，重载后关闭。451 区域限制有单独的状态。
- marketDataType 1/2/3/4 对应实时、冻结、延迟、延迟冻结。示例为 IBKR paper 只读场景。报价新鲜度独立于类型，QQQ 同时演示延迟和陈旧。旧盘口在失同步、重置、陈旧、断开或权限撤回时隐藏，后续增量无法恢复显示。切换标的、场所或产品会丢弃上一订阅和迟到事件。

## 合成数据与精度

沿用 U1 的固定点 OHLCV 生成器和聚合逻辑。BTC、ETH、QQQ 用种子 0 保存原有固定路径。其余标的用 1703–1711 的具名种子，由 32 位线性同余序列扰动固定路径，Binance 现货和永续分别给该币的种子加 1710 或 1720。价格、成交量、L1、深度、逐笔和永续字段全部由程序合成。回放基准固定为 2026-11-18 12:15:00 UTC，样本窗口只演示图表和状态。种子、整数步长及场所配置都在源码中。[行情 fixture](marketFixture.ts) · [回放适配器](fixtureAdapter.ts)

主图显示数据类别「价量历史」、来源、未复权和返回数量。AAPL 额外演示一根未闭合 K 线。选中 SMA、EMA、Wilder RSI、布林带或 MACD 时，图表按适配器返回的列画图，精确读数保留原小数位，预热或缺值留空并显示状态。指标样本是合成示意。真实指标由 finance F6 生产，行情与指标实接由 W2a 契约驱动。订单簿使用「订单簿细节」标注，名称由 U5 #21 统一。[共享组件](../../components/README.md) · [接口边界](../../api/README.md#行情视图适配层)
