# 策略、因子与配置回测

策略页通过上传 UTF-8 YAML 或选择登记版本获得同一编译预览。预览展示不可变策略版本与内容 SHA-256，以及引擎、组件版本、组合配方、数据、决策时钟、资金和成本。配置作业选择与该计划的 bars 和点时股票池匹配的数据集及时间窗。研究专用登记只展示说明、版本与研究结论。因子页展示版本定义、点时可用性、阶段、样本覆盖、Rank IC、ICIR、换手与费后基准。

## 前端适配层

[ResearchAdapter](adapter.ts) 是页面侧的 TypeScript 接口。app 注入 [合成适配层](fixtureAdapter.ts)。配置回测走 `/backtests?view=strategy` 和 `/backtests?run=<id>`。历史均线回测使用已有 web 客户端和 `/backtests?job=<id>`。

| 操作 | 前端所需语义 |
| --- | --- |
| `listStrategies`、`compile` | 目录区分配置回测与只读研究。校验接受登记的 ID 与版本，或本次选择的 YAML 内容。成功时返回绑定内容的不可变版本引用与预览，失败时返回诊断代码、字段路径和可用的行列。行列从 1 起算。非字符串键的路径指向所在映射，数值诊断的路径指向值本身，含序列下标。 |
| `listDatasets` | 按计划的日线源和点时股票池列出数据集及可运行的半开时间窗。 |
| `listFactors`、`factorReport` | 版本记录与评价报告分开读取。报告未生成时返回空值，统计值缺失时保留空值并显示「不可用」。 |
| `submit`、`byKey` | 提交固定版本、哈希、数据集和时间窗，以及调用方生成的幂等键。失败后先按键查询。只有明确查无原作业时才能重试，重试使用原参数与原键。 |
| `listRuns`、`run` | 列出作业与状态并按 ID 查询。成功详情返回运行清单、模拟成交账本与基准，排队及运行中的详情继续轮询。 |

静态应用已加载时，合成目录、报告和作业查询在断网及空查询缓存下可运行。web 适配仍使用在线查询模式。YAML 内容和客户端诊断不写入浏览器存储。会话存储保留待确认请求的不可变引用、时间窗、数据集与幂等键，合成适配层还保存演示作业元数据。通过两个入口提交同一版本和时间窗时，结果可比较，两次主动提交各有自己的作业 ID。对同一作业键重试会确认或返回原作业。

## 合成来源与校验

- [entry-exit.yaml](fixtures/entry-exit.yaml)、[target-weights.yaml](fixtures/target-weights.yaml) 和 [future-data.yaml](fixtures/future-data.yaml) 取自 finance `b21f241` 的 `strategies/fixtures/strategy-bundle/v1/`，用本仓库 Prettier 格式化并附合成来源标记。这些配置只引用示例目录。使用本地 F2 编译器运行 `finance-strategy compile <文件>` 可核对内容哈希和晚到日线诊断。
- 浏览器使用锁定的 js-yaml 4.3.2 解析上传文件。pnpm 补丁为 U3 提供在键转换前读取原始类型与位置的入口。映射键只接受字符串，序列、映射和其他标量键返回 `NON_STRING_KEY`。只为与内置合成配置等价的版本返回已核验的预览。可改注释、键顺序和等值十进制尾零。数值字面量须能精确表示为安全整数，带引号的十进制金额与权重保留精度。与晚到日线样例等价的文件返回 `FUTURE_DATA`，行列根据此次上传的标量位置计算。语法错误使用解析器的行列。局部校验支持 256 KiB 和 UTF-8 限制。[解析器补丁](../../../patches/js-yaml@4.3.2.txt)
- [目录与因子报告](fixtures/catalog.ts) 的指标、覆盖计数与日期均为手写常量。合成作业根据选定配方与时间窗，选择固定的权益、基准和 `SYN.XNYS` 账本值，快照摘要是演示标识。生成方式无需随机种子、真实行情、账户数据或外部调用。价格、数量、金额、权重和报告小数按十进制字符串呈现。
- `research.factor-momentum@1.0.0` 对应 F8 保留的只读研究 ID，此处展示登记状态与结论，省略原报告数据。

## W2b 接入

W2b 合并后，按 finance → web → frontend → fertile 的顺序更新契约。使用锁定的 web OpenAPI 和仓库生成流程，再在 [API 入口](../../api/README.md) 复用唯一 client 实现适配层。接入须明确上传校验如何返回可供提交与恢复的不可变引用，映射字段诊断和作业按键查询语义，以及读取 F7 运行清单/账本和 F8 评价。回测详情继续保留历史 `?job=` 路由。部署清单由 fertile 管理，frontend 的交付仍为 web 托管的静态文件。[构建说明](../../../docs/build.md)
